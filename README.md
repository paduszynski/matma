# Matma

Aplikacja do nauki matematyki dla dzieci: https://paduszynski.github.io/matma/

Moduły:
- **Fiszki mnożenie i dzielenie**: tabliczka mnożenia i dzielenie w zakresie 100. Odpowiedź wpisywana albo odwracanie karty, błędne fiszki wracają w tej samej rundzie, postęp zapisuje się w przeglądarce.

Cała strona to jeden plik `index.html` (GitHub Pages z gałęzi `master`).
